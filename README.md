# Terra Nova Analytics

**Data Science · Computational Modelling · Scientific Analytics**

Terra Nova Analytics is a company focused on the application of data science, statistical analysis, computational modelling and scientific computing to real-world problems.

## Website

[https://tnanalytics.github.io/](https://tnanalytics.github.io/)

## About

Terra Nova Analytics develops analytical and computational solutions that combine scientific knowledge, mathematical modelling and data analysis.

The company's areas of work include:

- Data Science
- Statistical Analysis
- Computational Modelling
- Machine Learning
- Scientific Computing
- Data Visualisation
- Geospatial Analysis
- Numerical Simulation
- Decision Support
